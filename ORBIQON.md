# Orbiqon deployment notes

This fork runs Shazim's instance at https://reply.orbiqon.com for @shazimbuilds.

All operator documentation is in [`orbiqon/`](orbiqon/README.md):

- `orbiqon/HOSTING.md`: where everything is hosted and how it is managed
- `orbiqon/AUTOMATION.md`: Google Drive, the campaign API, the agent skill
- `orbiqon/skill/SKILL.md`: the `/openreply-campaign` playbook
- `orbiqon/campaigns/briefs/`: one JSON per campaign

The upstream project's own README follows in `README.md`.
